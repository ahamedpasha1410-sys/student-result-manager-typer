# Project Scope

Student Result Manager is a command-line application built using Python, UV and Typer.

It helps manage student examination records.

## Features

- Add student details
- View student details
- Edit student details
- Delete student details
- Find topper
- Summarize results

## Target Users

- Teachers
- Students
- Educational institutions

## Out of Scope

- Database integration
- Authentication
- Attendance tracking
- Web interface
